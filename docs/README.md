# Project Documentation

This directory contains documentation about how the skills repository is
maintained and how it relates to `ACCESSIBILITY.md`.

- [Operating model](./OPERATING_MODEL.md) — ownership, review outcomes, and
  cross-repository principles.
- [Synchronization workflow](./SYNC_WORKFLOW.md) — local commands, discovery,
  review decisions, and pull request order.
- [Architecture](./ARCHITECTURE.md) — role-aware workflow structure and
  direction.
- [Role curation guide](./ROLE-CURATION_GUIDE.md) — how role and task mappings
  are curated.
- [AI-assisted accessibility audits guide](./AI_AUDIT_GUIDE.md) — when to use
  skills versus scanners during an audit.

For the installable skills, see [`../skills/`](../skills/). For evaluation
fixtures, see [`../evals/`](../evals/). The root
[`README.md`](../README.md) is the installation and contribution entry point.
